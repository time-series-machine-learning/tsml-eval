# REVE and LUNA deployment, 18 November 2026

`reve_luna_20261118.json` records every Python source hash in the isolated
aeon-neuro snapshot, checkpoint hashes, upstream revisions and run settings.
The snapshot includes the completed, uncommitted aeon-neuro adapters. It is
deployed independently of the existing environments' installed aeon-neuro.
Each generated job verifies its source files before running. Checkpoints are
copied from the desktop; clusters perform no downloads or package installations.

Run `check` and `start` with the standard Slurm runner:

- `experiments/iridisx_eeg_reve_luna_pilot.toml`: one epoch on
  ImaginedRightHandFeet and Alzheimers, two pretrained models, results in
  `~/Results/EEG-FM-Pilot`.
- `experiments/iridisx_eeg_reve_luna.toml`: 40 epochs maximum, patience 5,
  Core 90 only, results in `~/Results/EEG`. PostCovidVigilance is excluded by
  its blank `ch_names_any_length`. Pilot results never satisfy main-run tasks.

REVE Base uses batches of 8 for quadratic attention memory. LUNA Base retains
batches of 64. Other training and preprocessing settings follow the adapters'
documented shared fine-tuning recipe. These batch sizes and LUNA variant must be
reported with results. The new aliases also support matched random controls;
the two configs here schedule only pretrained fine-tuning.

All 89 named Core 90 datasets resolve coordinates locally. This does not verify
the inherited Option 1 mappings: repeated names and provisional CB/CFC/CCP
aliases require provenance review when interpreting results. Original metadata,
data arrays, labels and splits are preserved. The handover notes source overlap
between LUNA and AdultSeizures (Siena), and REVE and ImaginedFeetHands
(PhysioNet eegmmidb); the full overlap audit remains separate from execution.
