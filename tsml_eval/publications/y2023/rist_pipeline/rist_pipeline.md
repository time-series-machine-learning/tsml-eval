# Extracting Features from Random Subseries: A Hybrid Pipeline for Time Series Classification and Extrinsic Regression

This is the webpage for the paper "Extracting Features from Random Subseries: A Hybrid
Pipeline for Time Series Classification and Extrinsic Regression" from the
International Workshop on Advanced Analytics and Learning on Temporal Data (AALTD)
2023, which introduces the RIST pipeline.

The code, results files and instructions for running the experiments have moved to
their own repository:

<https://github.com/time-series-machine-learning/rist-pipeline-2023>

The RIST classifier and regressor are available in the
[aeon](https://github.com/aeon-toolkit/aeon) Python package as `RISTClassifier` and
`RISTRegressor`.

The original files remain available in the
[tsml-eval v0.7.0 release](https://github.com/time-series-machine-learning/tsml-eval/tree/v0.7.0/tsml_eval/publications/y2023/rist_pipeline).
